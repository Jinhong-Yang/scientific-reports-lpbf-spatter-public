\section{Evidence-layer and scope controls}
Historical measurements (H0), recovered original-code reproduction (R1), and the new study (N2) were stored separately. The N2 protocol hash, data-role receipts, code and environment hashes, run rosters, failed-run records, and test-access ledger are included in the reproducibility archive. W04 independent human review and W13 corrected-label interaction were excluded by the project decision owner before N2 outcome access. \section{Dataset manifest and grouping}
The derived manifest contains 5,632 file-hash-linked rows from 176 specimens. Each specimen contributes 32 retained images. The frozen split contains 112 training, 32 validation, and 32 held-out specimens, and views belonging to a specimen remain together. All 22 automated integrity checks passed: required files, hashes, box bounds, readability and JSON parsing had no critical failures. Image SHA-256 values were unique and no specimen or specimen--view group crossed splits. Coarse 64-bit dHash equality flagged 2,422 rows in 320 groups, including 195 cross-split groups; distinct byte hashes and sparse off-axis patterns prevent interpreting these as proven duplicates, but near-duplicate independence remains unresolved. Thirty-six repeated label hashes covered 72 rows, all within specimen and split. Optional position fields were null for 2,816 rows; required boxes were complete. The selected corpus came from accessible validation archives, not the entire provider dataset; three training volumes were unavailable. Manufacturing-build identity was not established. These limitations persist because the independent visual review was excluded.
